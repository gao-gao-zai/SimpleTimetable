# Android 0.1.1 当前实现

本次实现基于用户最后确认的 v18 原型。历史需求文档保留原貌；本文件记录后续设计决定、实际代码和验证边界。版本为首个可安装开发版，不等于所有目标设备已验收。

## 当前范围和历史需求修订

- 仅普通 Android 手机竖屏、Android 11 非 Wear OS 手表，兼顾 410×502 矩形屏与真正 1:1 方屏。vivo WATCH / BlueOS、SDK、蓝牙传输和快捷卡片已经延期，没有迁移旧环境的未提交 Android 骨架。
- “现在／课表／管理”三个入口。课表固定时间轴，日期按钮与左右手势翻页均有过渡；页面、抽屉有动画，应用内减少动画与系统关闭动画均生效。
- 保留两种小组件：课程卡片，以及可上下滚动、显示各节课程与教师的今日课表。后者没有删除；原型曾出现的五种重复信息组件没有进入应用。
- 浏览、编辑其他档案不切换运行数据；导入后需另行明确切换启用。所有编辑必须点击保存，保存成功立即写盘，再更新应用和系统入口。
- 抽屉点空白或返回会关闭；已有修改时先确认放弃。开发说明、模拟场景和原型工具没有放入首页。

## 系统刷新策略及边界

三处共用同一个引擎，均读取当前启用档案，不读取正在浏览的档案。

- 应用可见时每秒重算，进入后台停止页面秒循环，恢复时重新取时间。
- 通知与课程卡片使用原生 Chronometer 计时；数字由系统更新，不要求应用每秒重发 RemoteViews。
- 进度是快照：常驻显示服务在亮屏时约每 30 秒更新，只有小组件时请求约每分钟刷新；系统可能合并或延迟。课表组件的进度表示今日已结束课程比例，课程卡片与通知表示当前课程／间隔的已过去比例。
- 课程、临时有效期和日期边界独立安排下一次刷新。Android 11 可使用精确 AlarmManager；Android 12 及以上在系统允许精确闹钟权限时使用精确边界调度，设置页提供入口，否则使用系统允许的非精确调度。
- 熄屏、Doze、前台服务限制、系统进程清理及厂商省电策略仍可能延迟快照和换课。精确权限也不绕过系统的空闲频率限制。不承诺外部进度每秒刷新或所有设备熄屏时绝不延迟；应用本身恢复可见后会按当前时刻纠正。
- 目标杂牌手表的桌面是否开放小组件、系统通知版式与后台策略，必须在用户实际设备上验证。模拟器不能证明该厂商能力。

常驻服务只负责用户主动开启的信息展示，不产生上下课提醒；关闭通知不妨碍应用内课表和桌面小组件。

## ClassIsland 对照与导入范围

参考源码固定到 `235914a2fac1733cc2a169457c7bad4edb2ca2f6`，核对 Profile、Subject、ClassInfo、ClassPlan、TimeLayout、TimeRule、课表群及 LessonsService 的选择逻辑，并查看上游 Excel 导入向导。

- 导入 `Subjects`、`TimeLayouts`、`ClassPlans`、`ClassPlanGroups`、选定课表群、周规则、逐节启用状态与默认科目；按上课时段顺序对应 Classes，跳过行动时段，不执行附带内容。
- `OrderedSchedules` 的日期预定转换成对应日期的临时课表；未启用临时层的日期安排不偷偷激活，会给出导入警告。
- 原平台当前临时启用状态、行动、提醒、附加设置及设备校准不迁移。轮换基准采用导入时本周周一，预览明确要求核对学校周次。历史 ClassIsland 版本、插件扩展、未知自定义条件及全部运行行为尚未做兼容认证。
- 本项目临时层按已确认原型采用相交时段覆盖，保留未覆盖的常规课程。手动固定课表是显式本地功能。临时安排跨进程保留，与原平台部分临时运行状态不同。
- 临时课表优先于手动固定；随后自动群匹配中临时群、选定群、全局群有先后顺序。同优先级存在多份匹配时提示检查规则，不把正常的全局后备关系视为冲突。

不宣称兼容所有 ClassIsland 档案。JSON 结构、引用或时间无效时停在导入预览，不写坏现有档案。

## Excel / CSV

不是仅支持一个固定模板。可以选择每行课程记录并映射星期、开始、结束、科目和可选教师列；也可以选择周课表网格区域、星期方向、转置与已有时间表。

XLSX 支持工作表关系、共享字符串、内联字符串、合并区域及公式缓存值，不运行 Excel 公式或宏。CSV 支持引号、转义、换行和 UTF-8 / GB18030 编码，Excel 时间数值可转为作息时间。旧 `.xls` 不支持，需另存为 `.xlsx` 或 CSV。读取上限为原文件 8 MB、工作簿展开 20 MB、工作表 2000 行和 128 列；重叠时段、无效星期和引用错误不会直接写入。

## 技术与交付

最低 API 26，编译和目标 API 35，Java/Kotlin 字节码 17；应用 ID `io.github.gaogaoza.simpletimetable`。APK 包含 arm64-v8a、armeabi-v7a、x86、x86_64 原生依赖。主题算法来自 Material Components 1.12.0，具体依赖与升级限制见第三方说明。

用户随后授权使用 GitHub Actions 验证。本次 Android 实现和工作流提交到独立分支 `codex/android-app-v0.1.0`，使用硬件加速的 Android 11 手机、矩形手表、方屏模拟器；实际运行结果另附交付验证记录。

验证记录和 APK 哈希随交付报告提供。实际手机／手表安装、厂商桌面、TalkBack 听读、极大系统字体、熄屏省电与公网 NTP 可达性仍需实机验证。开发签名包适合安装试用；正式长期发布应由项目维护者保管稳定签名密钥。

### 0.1.1：配色与编辑体验

保留 Material Color Utilities HCT 主题生成。降低背景中性色的彩度，给课程容器明确的浅色/深色层级；对所有常用表面逐一校验正文、辅助文字、主题操作色和输入框轮廓的对比度（正文至少 7:1，辅助文字/操作色至少 4.5:1，轮廓至少 3:1）。科目徽章也按实际背景校正文字。抽屉和卡片显式使用对应的文字色，避免继承错误颜色。

主题和科目颜色使用预设色板、色相/饱和度/明亮度滑块；十六进制代码移入可选入口。时间表时段使用 24 小时制时分秒选择器，结束时刻支持 24:00，调整开始时间会保留原时长。时间表保存时段后返回时段列表。日期、轮换基准、临时安排有效期、换课日期统一使用适配小屏的日历；周次、时长、偏移使用有边界且显示单位的加减控件，精确数字仍可点击输入。课表课程逐节分卡显示，并展示实际继承的默认科目。导入的首行、区域角点、星期对应均通过选择控件设置，不再需要拼接区域代码或逗号列表。

抽屉遮罩改为独立的背景点击层，滚动区和固定保存栏保留独立的可访问性边界，避免滚动目标被保存栏遮挡。存储结构未变，0.1.1 发布版沿用 0.1.0 发布签名，可覆盖升级。
