## 资料与工具边界

官方入口：https://developers-watch.vivo.com.cn/api/system/bluetooth/ 、https://developers-watch.vivo.com.cn/api/storage/exchange/ 、https://developers-watch.vivo.com.cn/api/system/event/ 。独立 BLE 使用 `@blueos.bluetooth.ble`、`blueos.permission.BLUETOOTH`，不采用需要 device-rpc.aar/appid/密钥/运动健康的 BlueXlink。
旧协议未披露 UUID/报文；本次定义新协议，不宣称字节兼容。标准卡采用当前 widgetProvider 文档，避开弃用快捷卡。
历史工具输入是 BlueOS Studio 2.2.1 中 Linux 编译工具 1.0.12-beta.13 的五个 Sediment 分卷标识，不是 Library ID。当前环境没有可调用的 Sediment 下载工具，Library 简化查询也未找到工具包；尚未下载或运行它，不继承旧校验结果。官方工具未取得时可继续源码/逻辑测试，但不能宣称原生包编译成功。
历史上下文检索工具在本会话返回 unavailable；以父会话补充的已核对需求为准。
