# BlueOS 原生恢复工程

`app` 是 BlueOS UX 原生页面、独立 BLE GATT 服务端和 `type:js` 新标准卡；`watchface` 是同签名参考表盘。没有 WebView。原安卓工程保留在仓库根目录。

本次源码重建，不是恢复旧文件。平台无关测试：`cd blueos && npm test`。重新同步卡片/表盘自包含源码：`python3 blueos/scripts/sync-shared.py`。每个卡片的代码和资源均位于自己的目录。

将 `blueos/app`、`blueos/watchface` 分别作为项目用官方 BlueOS Studio 打开，选择官方 Toolkit 编译/打包。当前环境没有可调用的 Sediment 下载工具，无法取得历史五分卷的 1.0.12-beta.13；尚未完成官方编译，源码和 manifest 仍可能需要按取得的 SDK 调整，不能把 JS 测试当作 RPK 构建。不可用 zip 改扩展名代替 RPK。

标准卡 `minCardPlatformVersion:2000` 及独立 BLE 在 GT2 固件上的可用性必须真机检查。标准卡是新文档中的 js 卡，不冒充轻卡 widgetProvider；轻卡不在此版本实现。参考表盘的 `watch3000/id:3000` 是官方示例用的本地开发标识；正式服务端分配 ID 尚未取得，不擅自注册。不要将该示例 ID 当作可商店发布的正式 ID。

App 的 readonly snapshot.v1 通过同开发商 `exchange` 发布（同签名），公共事件仅是更新提示，消费者重读 exchange 并缓存；App 不发布完整私人档案到全局空间。exchange 重启会丢失，卡片/表盘会保留本地缓存并在超时/回拨时提示过期。复杂轮换/覆盖由 App 解析。App 在前台按分钟、保存后发布；后台被冻结时不承诺持续刷新，缓存最多一小时或规则变化边界有效。关闭 App 不伪称后台实时刷新。

手表独立保存亮/深两套主题和大字设置；系统时间。颜色和未知字段保留在档案传输内，但手表不提供种子色/科目色设置。无输入法编辑采用预设名称/教师、加减、日期选择、星期多选、时分秒三列。保存草稿前验证全部引用，未保存可放弃。复制/启用/删除均需要显式操作。临时停课用空科目补丁，当日结束恢复；在临时安排中可撤销。当前收藏是新增布尔字段，旧安卓档案无该字段时按 false 处理。

蓝牙：先在手表开启同步，再在安卓进入“手表同步”、授权附近设备、扫描选择服务并输入手表六位码。完整档案两端均需预览选择保存；保存成功后才发 SAVED 回执。结束同步会停广播并关闭服务。未收到 SAVED 时发送方不将传输完成当作保存完成。连接码只防误连，不宣称加密。原协议未取得，本协议是新的 v1，见 `protocol/README.md`。

签名：项目不含私钥/证书；App/卡片/表盘共享要求维护者本地使用同一签名。未经授权不生成新持久发布凭据。调试安装、无线方向、断线重连、存储满、App/表盘重启、过期提示及圆屏大字滚动仍待 GT2 真机验证。
