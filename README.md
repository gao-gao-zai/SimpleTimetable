# 简单课表 / SimpleTimetable

面向普通安卓手机、非 Wear OS 安卓手表及 vivo WATCH GT2 的课表工具。核心功能离线可用，支持科目、时间表、课表管理，以及当前课程、倒计时和进度展示。

项目处于需求整理阶段，尚未实现应用。安卓端优先交付，手机与小屏手表均为正式适配目标。
